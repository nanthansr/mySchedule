2026

Culprit

A CI gate for LangGraph agents that names which step caused the regression

An agent run is a chain of decisions. When it fails at step 7, step 7 is usually innocent - step 2 picked the wrong tool and steps 3 through 6 ran fine on bad data. The trace records where the failure surfaced, not where it started. Culprit stops reading the trace and re-runs it: rewind to step k, let that one decision be made again, let everything downstream run fresh, repeat. If the failure rate moves, step k mattered. git bisect for a process that isn't deterministic.

  • Two commands and three exit codes, because CI reads exactly one number: 0 clean, 1 regression attributed, 2 the tool itself is broken.
  • LangGraph is load-bearing, not garnish. It checkpoints before every step, so the checkpoint whose `next` is step k is the state one instant before step k decided anything.
  • A cheap pre-pass excludes steps that made no stochastic decision - replaying them is provably a no-op.
  • Round-robin budget spending, so when the budget runs out every step has been sampled the same number of times. Depth-first spending convicts whichever step happened to be measured well.
  • Runs offline on a scripted demo agent with a deliberately poisoned step, so every run has known ground truth. No API key needed.

2026

MLOps Fraud Detection Pipeline

Production ML observability: drift detection, alerting, and a tested incident path

Models degrade quietly. Feature distributions shift, confidence drifts, and by the time anyone notices the model has been wrong for weeks. The fraud model here is the vehicle; the detection layer around it is the point.

  • 284,807 transactions, 492 of them fraud - a 577:1 imbalance. Logistic regression collapsed on recall, so XGBoost with scale_pos_weight=577.
  • PR-AUC as the primary metric, not ROC-AUC. A model that predicts "always legitimate" scores 0.97 ROC-AUC on this data; PR-AUC exposes that.
  • 2-5 ms per prediction through FastAPI with typed request schemas.
  • Promotion without redeployment, via an MLflow @champion alias.
  • simulate_incident.py replays a fraud spike and a distribution shift, so the Grafana alert rules are tested rather than assumed.
  • Runs at $0/month on an Oracle Cloud Always Free ARM VM behind Nginx, after an earlier AWS ECS Fargate deploy using keyless OIDC.

2026

Pomofocus

A macOS menu bar Pomodoro timer that never shows a number

A visible countdown is itself a context switch - you look at it, and the looking is the interruption. So this one shows a ring that ripens instead of digits that tick.

  • Timing is anchored to an end date rather than a decrementing counter, so closing the lid mid-session doesn't corrupt the remaining time.
  • Native Swift, zero third-party dependencies.
  • Five tests, and no network calls at all.
  • It promises nothing it cannot deliver - no waitlist, no coming-soon link.
  • Swift
  • AppKit
